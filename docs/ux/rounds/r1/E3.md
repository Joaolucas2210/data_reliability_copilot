## 5. Strengths observed (for calibration)
Coherent token system with full light/dark parity and no axe contrast violations in either theme. Epistemic tags
distinguished by label, icon *and* border shape. Clear 3 px focus ring. ARIA tabs with arrow keys. Citation chips
move focus to the evidence. Reduced motion respected. Loading, error and retry are consistent on list pages. No page
overflow at 1440, 1024, 768 or 390.

## 6. Limitations
- Shared environment: other evaluators were mutating data at the same time, so list contents changed between captures.
- Several states were produced by intercepting API responses (500, abort, 403, running, empty-note reject) rather than by
  real backend conditions.
- Dev server (React StrictMode) rather than a production build.
- Chromium only; no Safari/Firefox, no real mobile devices or zoom-to-400 % test separate from the 320 px viewport.
- Screen-reader behaviour was inferred from DOM/ARIA and axe, not tested with NVDA/VoiceOver.
- 1024/768 were checked with the overflow sweep and selected screenshots, not every route visually.
